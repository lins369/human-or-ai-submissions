# Report assembly

Keep content organized by question, not by person. Authors complete separate
files in `sections/`; the final report includes them with LaTeX `\input`.
Current status: Q1 covers seven classifier families plus an SVD LR control,
with 64 configurations / 192 fold fits and a completed section; other sections
remain stubs. `output/pdf/q1_results.pdf` is a compiled Q1 review copy, not the
completed team report. Compile its source from repository root with:

```sh
mkdir -p tmp/pdfs
pdflatex -interaction=nonstopmode -halt-on-error -jobname=q1_results -output-directory=tmp/pdfs report/q1_preview.tex
```

Run a second pass if LaTeX requests it, and copy the resulting PDF to
`output/pdf/q1_results.pdf`. Model and CV figures are generated by the supervised
track's `report_expanded_q1` command. Review the rendered pages after changes.
`sections/q1_expanded_search.tex` contains the exact search ranges/refinements.

`report/archive/` for comparison.
